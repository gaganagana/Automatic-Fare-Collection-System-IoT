## Important email conflict

Firebase Authentication requires each email address to belong to one account. `gaganacp2002@gmail.com` is currently listed for both Gayathri and the admin Gagana. Those cannot be two separate Firebase Auth accounts with the same email.

Before creating accounts, choose a different email for either Gayathri or Gagana. Do not share passwords in chat or source code.

## Required Firestore profile documents

After Firebase Authentication accounts are created, create/update a `users/{firebaseAuthUid}` document for each account:

Passenger:

```text
username: passenger name
email: Firebase email
role: passenger
linkedUid: RFID UID
createdAt: server timestamp
```

Admin:

```text
username: Gagana
email: gaganacp2002@gmail.com
role: admin
```

## Card documents

Create `wallets/{RFID_UID}` documents for the seven cards. The UI does not display wallet balance to passengers, but the existing prototype model keeps a backend balance for the hardware/simulator fare logic.

Suggested starting values for the prototype:

- Valid cards: ₹200
- Low-balance cards `3D085006` and `21DB3E0A`: ₹5

Fields:

```text
uid: RFID UID
holderName: passenger name
balance: numeric starting balance
linkedFirebaseUid: passenger Firebase Auth UID
isDemo: false
createdAt: server timestamp
lastUpdated: server timestamp
```

The application does not create Firebase Auth accounts automatically from this file; Firebase Auth UIDs are generated by Firebase and must be inserted into the profile/card documents after the accounts exist.
