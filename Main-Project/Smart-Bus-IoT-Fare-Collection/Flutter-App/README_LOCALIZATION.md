# Smart Bus localization

The app supports English (`en`), Kannada (`kn`), and Hindi (`hi`). Changing the language from the existing language selector updates the Flutter UI immediately through `AppState.setLocale()`.

The fixed 18-stop route now has display names for all three languages. Firebase, Firestore, RFID UID data, and hardware stop logic continue using the existing canonical stop names/IDs so localization does not break the hardware integration.

RFID/fare announcements generated by `AppState` also use the selected language's localized stop name.

The Login/Sign Up and Firebase session behavior remains unchanged.
