3. DFD Level 2 — Process 2.0 (Automated Fare & Ticketing Engine)

Detailed sub-process decomposition of the automatic stop-based fare deduction algorithm.

Sub-Process Step-by-Step Logic

Sub-Proc Name Mathematical & Logical Rule
2.1 Determine Tap Mode if (wallet.onboard == false) => Entry Mode; else => Exit Mode;
2.2 Boarding Validation & Tagging if (balance >= 10.0 && active == true) { wallet.onboard = true; wallet.entryStop = currentStop.id; openDoor(); } else { denyEntry(); }
2.3 Retrieve Journey Indices Lookup index of entryStop and exitStop in Route 25A 18-stop array.
2.4 Compute Flat Fare stopsCount = max(1, |exitIndex - entryIndex|);
fareAmount = stopsCount * 10.0;
2.5 Debit Balance & Reset wallet.balance = wallet.balance - fareAmount;
wallet.onboard = false;
wallet.recentExit = currentStop.id;
2.6 Generate Audit Record Create immutable FareTransaction entry in Firebase and local transaction feed.
